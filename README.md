# The New River Murder, 1878

An illustrated timeline of the 1878 murder of Thomas Edward Ward at New River, Charlotte County, New Brunswick; the trial; and the hanging of Thomas Dowd at St. Andrews on January 14, 1879.

The site is a single page (`index.html`) with its source images in `img/`. The images include the 1878–80 newspaper reports (original pages, Newspapers.com printouts, and the Charlotte County Archives' typed transcriptions of the Bay Pilot and St. Andrews Standard), the coroner's inquest report, the 1851 census, and Library and Archives Canada file entries.
